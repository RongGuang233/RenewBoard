# 资产与学费同步

资产页只回答“现在有多少资产、多少负债、余额怎样变化”。订阅付款明细继续留在账本，设备购买成本也不自动视为现有资产。

## 页面与操作

底部栏目按“到期、资产、账本、设备、设置”排列。资产首页为居中的白色净资产总览和分类白卡，眼睛按钮在净资产标题旁，添加与管理入口在右上角；“查看趋势”进入历史趋势，不在首页展示图表或负债率。分组可折叠，管理页可调整分组顺序，两项显示偏好保存在本机。分组标题显示实际余额合计，多币种分别列出；部分余额不计入时另标“其中计入”，不把净资产口径当成账户余额。

添加账户时先点选带图标的账户类型，再填写名称、当前余额、日期和币种，按需填写折算汇率、备注。账户详情或列表长按可打开更新余额面板，保存前显示原余额与差额；“纠正上次录入”替换账户最近一条记录。净资产趋势保留实际观察并标记校正，不把它当收入。账户归档仅收起列表，是否计入净资产由独立开关控制。归档账户在右上角“账户管理”中查看和恢复。

家教学费首页分别汇总已核实的待上课预收款、已上课待收款，学生明细进入二级页；“查看学生”不触发网络请求，“刷新”读取已发布余额，首次新增学生仍需确认导入。

| 分类 | 默认统计 |
| --- | --- |
| 资金账户 | 现金、银行卡、微信、支付宝余额计入资产；负余额计负债 |
| 投资理财 | 手动填写当前价值，计入资产；不自动计算收益 |
| 待收款 | 借出款、押金等计入资产 |
| 负债账户 | 信用卡、花呗、贷款等剩余全部欠款计入负债；信用额度不是资产 |
| 预付余额 | 默认不计入；饭卡默认计入，可逐账户调整 |
| 家教学费 | 已核对的正余额计负债，负余额计应收款，零余额结清 |

净资产 = 已计入资产 − 已计入负债。账户已反映真实资金变化，不再减一次账本支出。外币保留原币，手动填写“1 原币 = 多少 CNY”后计入；未折算或未核实账户单独提示，汇总标为已知净资产。

已有话费与 API 余额自动出现在预付分类，点击来源账户更新，不再建立第二份余额。话费余额沿用现有月费估算逻辑。DeepSeek 刷新成功后使用充值余额，赠送部分不计入；手动更新后需重新确认本人充值部分或再次刷新。其他平台本人充值额需手动确认，未知不纳入。

余额变化形成实际记录点。未记录的日期不回填；账户加入、是否计入和折算依据变化标记为统计范围调整。该趋势是观察时刻的汇总，不是完整的日常收支账。

## 家教学费为什么扣除预收款

银行卡有 5,000 元，其中 2,000 元是尚未上课的预收款：资产 5,000、学费负债 2,000，净资产 3,000。上课消耗 300 元后，银行卡仍为 5,000、学费负债变为 1,700，净资产 3,300。手机不会把 300 元再次加进银行卡。

家长欠费意味着已经上课而尚未收款，作为应收款，不代表可立即使用的现金。银行余额始终按实际余额单独更新。

## 首次连接与日常更新

1. 经用户确认后，在自己的服务器复用现有 OpenResty 配置密文中转（不新增常驻服务）：独立上传与读取令牌，HTTPS 地址，服务器不持有解密密钥。
2. LessonManager 安装可选加密依赖，在设置中的“订阅簿学费同步”填写地址、上传令牌并生成加密密钥。凭据由 macOS 钥匙串保存，不进入课时业务备份。
3. 手机“资产 → 右上角菜单 → 学费同步 → 连接设置”填写同一地址、独立读取令牌和同一加密密钥。本机用 Android Keystore 加密保存。
4. 在 LessonManager 完成一次或几次记课后点击“发布学费余额”；手机点击“刷新学费余额”。没有后台持续同步，也不从手机反写课时簿。

第一次读取先选择学生，默认勾选在读学生，暂停与归档学生可手动选择，未结清账户仍列出。新学生也先选择；已有学生按标识更新，重命名不产生重复账户，手机别名与统计开关保留。相同文件反复读取不重复增加余额或历史；较早发布的数据不覆盖较新数据。

来源中缺失的学生保留上次余额并提示，不自动清零或删除。首次未核实的余额只显示，不进入总数；已确认账户遇到未核实新值时保留已确认余额，并提示来源待核实。来源发布时间与手机读取时间分别显示。下载、解密或校验失败保留全部原数据。

## 数据边界

同步摘要仅包含版本、发布时间、学生标识/名称/状态、整数分余额及核实标记，不包含课程明细、家长备注或联系方式。AES-256-GCM 在电脑加密，在手机解密；HTTPS 和分别认证的上传、读取保护传输入口。服务端仅以原子替换保存最新成功上传的密文。

“学费同步加密”仅针对这个同步通道。手机本地业务数据库以及用户主动导出的完整 JSON 备份包含可读的资产和学生余额；现有 WebDAV 也是 HTTPS 传输的明文业务备份。连接令牌、加密密钥、平台 API 密钥不包含在这些备份中，新手机需重新连接。断开学费连接保留本地账户，不删除服务器密文。

新增资产数据使用 JSON 备份版本 3；旧版本 1、2 可正常读取。Room 仍使用原有账本记录，资产字段缺失时取空值，不重建或删除已有业务表。恢复备份保留其中的资产历史，不伪造新的余额变化。

完整线协议、公开测试向量与 OpenResty 部署改动见[中转目录](../tools/tuition-relay/README.md)。真实服务器连接、检查与部署需要先获得用户确认。
