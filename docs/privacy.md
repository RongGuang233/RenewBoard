# 订阅簿隐私说明

适用于本仓库当前版本，更新日期：2026-09-06。

订阅簿没有广告、行为分析或开发者运营的数据接收服务。订阅、权益、金额（包括手动确认的付款日人民币实付金额）、续费记录、备注、提醒设置和手动汇率保存在本机应用私有目录的 Room 数据库中。数据库本身未实现额外的应用层加密。应用不接入银行或支付平台，不执行扣款、支付或真实订阅的取消；“续费”操作仅记录用户输入的信息。

用户点击“检查更新”时，应用向 GitHub 公共发布接口读取最新版本号和更新说明；不发送账本、账号或 WebDAV 凭据。GitHub 可接收 IP 地址及应用版本。用户选择下载后，在浏览器中打开本项目发布页，由用户完成 APK 安装。

只有用户自行配置 HTTPS WebDAV 地址、账号和专用应用密码并启用备份后，应用才向该服务器上传完整业务 JSON。JSON 包含上述账本与设置、记录标识及备份时间，不包含 WebDAV 账号或应用密码；连接服务器时，账号与应用密码会通过 HTTPS 请求中的认证头发送给用户指定的服务商。传输使用 HTTPS，备份文件没有额外端到端加密，服务器提供者能够读取其内容，并可能记录 IP 地址等连接信息，适用其自己的隐私规则。

启用后，账本变更触发延迟备份，后台也会按系统调度周期尝试备份。应用保留最近 10 份自动备份，手动备份不参与自动清理。断开 WebDAV 会清除本机保存的连接配置与密码并停止后续上传，不删除本机账本或远端已有备份；已存远端文件需在相应服务中管理。

专用应用密码使用 Android Keystore 管理的 AES-GCM 密钥加密后保存在本机；服务器地址、账号和备份状态保存在本机应用私有设置中。此保护不代表整个账本加密。清除应用数据或卸载会移除本机数据，远端备份仍然存在。应用声明 `android:allowBackup="false"`，不主动接入 Android 自动云备份；不同设备厂商的设备迁移行为以系统实现为准。

通知权限只用于本机到期提醒。通知可能显示订阅或权益名称和到期日，其锁屏可见性由系统设置控制。应用不请求通讯录、定位、相册或短信权限。

本说明描述代码实现，不代表已完成任何特定 WebDAV 服务商、设备迁移或应用商店的认证。实际测试范围见项目验收记录。
